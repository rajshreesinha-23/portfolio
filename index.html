Projects

RegulaLens AI

Regulatory document analysis

Upload regulatory documents and ask questions about them. Answers come from the document text through retrieval-augmented generation, so each response can be traced back to its source.

  • RAG
  • Gemini API
  • Python
  • Web frontend
How it works

Problem

  • Regulatory documents are long and dense. Finding the clause that answers a specific question takes manual reading.

Approach

  • Documents are split into passages and indexed for retrieval.
  • The /ask endpoint retrieves the most relevant passages and passes them to Gemini to compose an answer.
  • API keys are loaded from a .env file and kept out of the repository.

Sentinel AI

Multi-agent fraud investigation

An AI risk manager that investigates transactions with a team of specialist agents. They agree and disagree, and explain their reasoning, instead of returning a bare fraud score.

  • Multi-agent systems
  • LLMs
  • Risk scoring
How it works

Problem

  • Companies struggle to tell fraudulent transactions from innocent ones, and manual investigation does not scale.

Why several agents

  • A single agent has to hold every concern at once. Splitting the investigation lets each specialist handle one narrow job, the way a team divides work.

Vajra Pramana

In progress · SIH 2026 internal hackathon

A platform for human-authorised AI access. It verifies identity, checks permissions, and requires risk-aware approval before an AI system can perform a sensitive action.

  • Next.js
  • Node.js
  • Hyperledger Fabric
  • PostgreSQL
How it works

Problem

  • AI agents increasingly act on behalf of people. Sensitive actions need a verifiable record that a human approved them.

Approach

  • Identity verification and permission checks run before a request is considered.
  • Higher-risk actions require explicit human authorisation.
  • Approvals are recorded on a Hyperledger Fabric ledger. PostgreSQL holds application data.
