RegulaLens AI

Regulatory intelligence platform that helps compliance teams analyze circulars and detect changes between versions.

  • FastAPI backend with 4 REST endpoints (upload, list, retrieve, compare) documented in Swagger UI
  • PDF validation and page-wise extraction via PyMuPDF, preserving page numbers for traceability
  • difflib comparison API returning inserted, deleted and replaced blocks as structured JSON
  • React dashboard built for planned citation-backed RAG Q&A

FreelanceVault

Blockchain freelance escrow that holds client funds and releases payment on approval.

  • Full lifecycle: creation, funding, submission, approval, release and refunds
  • Role-based access control; ReentrancyGuard from OpenZeppelin on fund transfers
  • Review-period timeout for payment claims
  • On-chain events for every state change, giving an auditable payment history
